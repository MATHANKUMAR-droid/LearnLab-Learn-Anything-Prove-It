# LearnLab-Learn-Anything-Prove-It
Built LearnLab — an AI-powered learning platform where you type in ANY topic and get a full personalized course in seconds.

✅ Sign up with email OTP verification
✅ AI-generated lesson + examples + mock questions on whatever you want to learn 
✅ Auto-generated 20-question test to check your understanding 
✅ Downloadable certificate of completion when you pass

Built end-to-end with Python (Flask) + Claude AI for content generation + a full glassmorphism UI on the frontend. Everything — users, sessions, test scores, certificates — logged automatically to Excel.

From "I want to learn X" to "I have a certificate in X" in one sitting. 🎓

Shipped a full-stack AI learning platform this week: LearnLab.

🔧 Stack: Python (Flask) backend, vanilla HTML/CSS/JS frontend, Claude API for dynamic content generation, openpyxl for data logging, reportlab for PDF certificate generation.

🧩 What it does: 
1️⃣ Email OTP-based auth (sign up / sign in) 
2️⃣ User describes a topic → Claude generates a full lesson (sections, key concepts, worked examples, mock questions)
3️⃣ Auto-generated 20-question assessment, graded server-side 
4️⃣ PDF certificate issued on a passing score, downloadable instantly

Every user, OTP, session, test attempt, and certificate gets logged to an Excel workbook for full auditability — no black-box data.

Fun one to build end-to-end, from auth flow to AI content generation to PDF rendering. 🛠️
